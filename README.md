# Valdis Story Modding Collection

The aim of this Github Page is to share every Valdis Story: Abyssal City mods as either xDelta Patches or whatever the modder used. To use them, you must have a non-cracked version of the game (that can be found on [Steam](https://store.steampowered.com/app/252030)) and for some of them other tools (such as an [xDelta Patcher](https://kotcrab.github.io/xdelta-wasm/)). Take your data.win file, the xDelta patch, apply it and there you go, mod installed !

If you're interested in our modding community, feel free to join [our discord server](https://discord.gg/AJQB4hfbsX) or talk about it on [this Steam Page](https://steamcommunity.com/app/252030/discussions/0/800089396009375870/).

If you want your mod to be shared here, just ask BeerMoney on the discord server.


## Modpacks
 - [Expanded Abyss v0.2](http://marcherfu.github.io/VSACModding/Mods/Modpacks/Expanded%20Abyss%20v0.2.xdelta) by Rosgath : a change to the core route progression with a bunch of great ideas working towards an expansion of the game.


## Quality of Life
 - [Better Dummy](http://marcherfu.github.io/VSACModding/Mods/Quality%20of%20Life/BetterDummy.xdelta) by BeerMoney : changes the Dummy to take true damages for better calculations.
 - [Revamped Library](http://marcherfu.github.io/VSACModding/Mods/Quality%20of%20Life/RevampedLibrary.xdelta) by BeerMoney : changes the position of NPCs in the Library for better navigation.


## Bugfixes/Unfixes
 - [Decoy Warp Unfix](https://marcherfu.github.io/VSACModding/Mods/Bugfixes%20and%20Unfixes/DecoyWarpUnfix.xdelta) by BeerMoney : enables back the Decoy Warp Glitch used by Speedrunners during the Reina's WW route era.
 - [Valdis' Better Story](https://marcherfu.github.io/VSACModding/Mods/Bugfixes%20and%20Unfixes/ValdisBetterStory.xdelta) by BeerMoney : fix 2 minor issues and 1 major issue at once :
   - Anemone's icon of the Max HP gained upon getting S-Rank is now correctly displayed.
   - Armor of the Grey Knight now shows the correct description whether you're in Arena or "Story" Mode.
   - Resetting your Skills now reset the Soul Affinity given by getting them correctly, which avoids Soul Affinity manipulation.


## Gameplay
 - [Cheat Mode](http://marcherfu.github.io/VSACModding/Mods/Gameplay/CheatMode.xdelta) by BeerMoney : add a tons of resources to make the game way easier.
 - [Dismantle Weapon](http://marcherfu.github.io/VSACModding/Mods/Gameplay/DismantleWeapon.xdelta) by BeerMoney : adds a third item to Mesmer that allows the player to revert back to level 1 the currently equipped weapon, refunding every resources with it.
 - [Infinite Levels](http://marcherfu.github.io/VSACModding/Mods/Gameplay/InfiniteLevels.xdelta) by BeerMoney : adds infinite leveling to the game, with small balance changes past Lv25 to make it less broken.
 - [Soul Affinity Rework](http://marcherfu.github.io/VSACModding/Mods/Gameplay/SoulAffinityRework.xdelta) by BeerMoney : rework the Soul Affinity system to avoid forcing the player to always go Dark and offer various building paths and change the way the cap of Soul Boosts is calculated. Does work with the Infinite Levels mod as well.
